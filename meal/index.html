2. 点「Generate new token」，取个名字（如 meal-sync）
3. Repository access 选「Only select repositories」→ 选 gadgetry 仓库
4. Permissions → Repository permissions → Contents 设为 Read and write
5. 生成后复制 token（以 github_pat_ 开头），填到下面
6. 仓库名填 gadgetry，数据会存在 data/meal.json
