🔗 GitHub 云同步

配置后每次打分自动同步到 GitHub 私人仓库，对方打开 app 自动拉取最新数据，无需手动导入导出。

▶ 设置方法（点击查看）
1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. 点「Generate new token」，取个名字（如 love-score）
3. Repository access 选「Only select repositories」→ 选一个仓库（或先新建一个空的）
4. Permissions → Repository permissions → Contents 设为 Read and write
5. 生成后复制 token（以 github_pat_ 开头），填到下面
6. 你和对象填相同的 token 和仓库名即可互通
